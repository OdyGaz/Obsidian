# Notes on Obsidian
# 📝 Οδηγός Dataview & Metadata στο Obsidian (για Αρχάριους)

Αυτός ο οδηγός επεξηγεί τις βασικές έννοιες των μεταδεδομένων (metadata) στο Obsidian, πώς λειτουργεί το πρόσθετο (plugin) **Dataview** και πώς μπορείτε να οργανώσετε τις σημειώσεις σας σαν βάση δεδομένων.

---

## 1. Τι είναι τα Μεταδεδομένα (Metadata);
Τα μεταδεδομένα είναι «πληροφορίες για τις πληροφορίες σας». Στο Obsidian, είναι οι ετικέτες, οι ημερομηνίες, οι κατηγορίες ή τα projects που ορίζετε στις σημειώσεις σας, ώστε να μπορείτε να τα αναζητάτε εύκολα. 

Υπάρχουν δύο βασικοί τρόποι για να τα γράψετε:

### Α. YAML Frontmatter / Properties (Γενικό Πρότυπο)
Το **YAML Frontmatter** είναι ένα κομμάτι κειμένου που μπαίνει **μόνο στην αρχή** της σημείωσης και ορίζει ιδιότητες για **ολόκληρο το αρχείο**.

* **Πώς γράφεται:** Ανάμεσα σε δύο σειρές με τρεις παύλες (`---`), χρησιμοποιώντας τη σύνταξη `κλειδί: τιμή`.
* **Obsidian Properties:** Το Obsidian παρέχει ένα όμορφο οπτικό περιβάλλον (με κουτάκια και επιλογές) πάνω από αυτόν τον κώδικα, το οποίο ονομάζει "Properties".
* **Είναι αποκλειστικό του Obsidian;** Όχι. Το YAML και το Frontmatter είναι παγκόσμια τεχνολογικά πρότυπα. Χρησιμοποιούνται ευρέως στον προγραμματισμό (π.χ. Docker, Kubernetes) και σε πλατφόρμες δημιουργίας ιστοσελίδων (π.χ. Jekyll, Hugo).

```yaml
---
project: Project Alpha
status: Σε εξέλιξη
date: 2026-05-25
---
```

### Β. Inline Πεδία / Inline Fields (Ειδικά για το Dataview)
Τα **Inline πεδία** σάς επιτρέπουν να γράφετε μεταδεδομένα **μέσα στο σώμα του κειμένου** ή **μέσα σε λίστες (bullet points)**, χωρίς να χρειάζεται να πάτε στην αρχή της σελίδας.

* **Πώς γράφονται:** Χρησιμοποιούν τη διπλή άνω-κάτω τελεία (`::`), συνήθως μέσα σε αγκύλες `[κλειδί:: τιμή]`.
* **Γιατί είναι χρήσιμα:** Είναι ιδανικά για καθημερινές σημειώσεις (Daily Notes) όπου θέλετε να καταγράψετε διαφορετικά projects στην ίδια σελίδα.

```markdown
- [project:: Project Alpha] [start:: 10:00] [end:: 11:00] [desc:: Συνάντηση με την ομάδα]
- [project:: Project Beta] [start:: 11:30] [end:: 12:30] [desc:: Σχεδιασμός λογοτύπου]
```

---

## 2. Τι είναι το Dataview;
Το **Dataview** είναι ένα πρόσθετο (plugin) για το Obsidian που διαβάζει τα μεταδεδομένα (YAML ή Inline) και δημιουργεί αυτόματα δυναμικούς πίνακες, λίστες ή ημερολόγια.

### Ανάλυση ενός Κώδικα Dataview
Ας δούμε τι κάνει ο παρακάτω κώδικας βήμα-βήμα:

```dataview
TABLE 
    L.project AS "Project", 
    L.MyTags AS "Tags", 
    L.date AS "Ημερομηνία", 
    L.start AS "Έναρξη", 
    L.end AS "Λήξη", 
    L.desc AS "Περιγραφή", 
    L.decision AS "Απόφαση", 
    L.attendees AS "Συμμετέχοντες", 
    L.mood AS "Mood", 
    L.files AS "Αρχεία"
FROM "00_Daily"
FLATTEN file.lists AS L
WHERE L.project != null
SORT L.date DESC, L.start DESC
```

#### Τι σημαίνει η κάθε γραμμή;
1. **`TABLE ... AS ...`**: Δημιουργεί έναν πίνακα και ορίζει τις στήλες. Για παράδειγμα, παίρνει το πεδίο `L.project` και το ονομάζει "Project" στον πίνακα.
2. **`FROM "00_Daily"`**: Λέει στο Dataview να ψάξει μόνο για αρχεία που βρίσκονται μέσα στον φάκελο με όνομα `00_Daily`.
3. **`FLATTEN file.lists AS L`**: 
   * Το `file.lists` περιέχει όλες τις λίστες (κουκκίδες) μιας σημείωσης. 
   * Η εντολή `FLATTEN` παίρνει κάθε κουκκίδα ξεχωριστά και της δίνει ένα προσωρινό όνομα (μεταβλητή), το **`L`** (από τη λέξη List). Αντί για `L`, θα μπορούσαμε να είχαμε γράψει `AS grammi`.
4. **`WHERE L.project != null`**: Φιλτράρει τα αποτελέσματα ώστε να εμφανίζει μόνο τις κουκκίδες που έχουν συμπληρωμένο το πεδίο `project` (δηλαδή το project δεν είναι κενό/null).
5. **`SORT L.date DESC`**: Ταξινομεί τα αποτελέσματα από το πιο πρόσφατο στο πιο παλιό.

### Τι σημαίνει η τελεία (`.`) στο `L.project`;
Η τελεία χρησιμοποιείται για να δείξει σχέση εξάρτησης (dot notation). Σημαίνει: «Μπες μέσα στη γραμμή λίστας **`L`** και φέρε μου την τιμή του πεδίου **`project`**».

## 3. Πώς να φιλτράρετε τον πίνακα για ένα συγκεκριμένο Project

Αν θέλετε ο πίνακάς σας να μην δείχνει όλα τα projects, αλλά μόνο ένα συγκεκριμένο (π.χ. το **"Project Alpha"**), πρέπει να τροποποιήσετε τη γραμμή `WHERE`. 

Υπάρχουν δύο τρόποι για να το κάνετε αυτό:

### Τρόπος Α: Απόλυτη Ταύτιση (Exact Match)
Εμφανίζει μόνο τις γραμμές που το project είναι ακριβώς "Project Alpha".

```dataview
TABLE 
    L.project AS "Project", 
    L.date AS "Ημερομηνία", 
    L.desc AS "Περιγραφή"
FROM "00_Daily"
FLATTEN file.lists AS L
WHERE L.project = "Project Alpha"
SORT L.date DESC
```

### Τρόπος Β: Μερική Ταύτιση (Contains)
Εμφανίζει τις γραμμές που το project περιέχει το κείμενο "Project Alpha" (χρήσιμο αν έχετε ονομάσει κάτι π.χ. "Project Alpha - Φάση 1").

```dataview
TABLE 
    L.project AS "Project", 
    L.date AS "Ημερομηνία", 
    L.desc AS "Περιγραφή"
FROM "00_Daily"
FLATTEN file.lists AS L
WHERE contains(L.project, "Project Alpha")
SORT L.date DESC
```
